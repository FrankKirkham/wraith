# Wraith *v0.3.0*

DJing without the decks: A virtual DJ controller controlled entirely with your hand movements in the air using your webcam. It works by utilising the latest AI/ML tools for detecting hand movements in video and maps this into MIDI signals a DJ software like Mixxx can understand.

## Latest update (v0.3.0)

- **New app window**: Wraith now opens in its own window showing your camera feed, with the hand skeleton drawn over it if you want it.
- **Settings menu**: change settings from the Settings button in the menu bar instead of editing a file. Changes apply straight away and are saved for next time.
- **Stepped controls**: each control can be set to jump between fewer values instead of moving smoothly, making it easier to land on a value and hold it. The EQ steps always include the centre point, so you can snap an EQ straight back to neutral.
- **Cut-only EQ**: each EQ knob can be set to only cut, so your hand's full range covers the area from fully cut up to neutral, with no boost.
- **Centre line**: an optional line down the middle of the camera feed shows where deck 1's side ends and deck 2's begins.
- **Active height**: choose how much of the camera's height the controls use, so you don't have to reach the very top or bottom of the screen where hand tracking is less reliable. Pinching above or below it sets the control to its highest or lowest value.
